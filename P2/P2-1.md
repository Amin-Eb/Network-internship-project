# Clearing dns cache

Based on the system many approaches are appliable to clear the dns cache, in ubuntu 24.04 i did :
```
sudo resolvectl flush-caches
```
and with below command you can manage the result of clearance:
```
sudo resolvectl statistics
```

## Running wireshark and capturing the traffic

Run the wireshark and capture the traffic from your internet interface.

```
sudo wireshark
```

We want to capture and save the traffic, so after starting and finishing the capture by wireshark GUI, we save the output file as "p2-1.pcap".

### ‌Breaking down one of requests

** Successful request **
Asking the dns server by packet: 
```
"49","2.799537518","192.168.1.104","10.255.255.254","DNS","68","Standard query 0x5826 A divar.ir"
```
The response:
```
"55","2.840061882","10.255.255.254","192.168.1.104","DNS","100","Standard query response 0x5826 A divar.ir A 185.166.104.3 A 185.166.104.4"
```

my session(192.168.1.104) asked the dns server (10.255.255.254) in this case local server, for the ip divar.ir
A notes that the version of ip is ipv4.

the response shows that the wanted ip address is 185.166.104.4

** Unsuccessful request **

Asking the dns server by packet:
```
"3663","31.931543266","192.168.1.104","10.10.10.10","DNS","79","Standard query 0x3c31 A www.salamvaaleik.nz"
```

The response :
```
"3679","32.122855458","10.10.10.10","192.168.1.104","DNS","141","Standard query response 0x3c31 No such name A www.salamvaaleik.nz SOA loopback.dns.net.nz"
```

it says that www.salamvaaleik.nz is not valid/defined in dns server that we asked from.
