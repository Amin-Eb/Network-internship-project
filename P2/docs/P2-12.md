# Running the Reporter
<img width="995" height="606" alt="image" src="https://github.com/user-attachments/assets/fd2580ed-3945-46fd-9d37-5c83c680b73d" />
In this part you can run the final reporter executable to capture traffic from interface and present the data with Grafana!  

## Build
Build the target statistics with :  

```
[proxychains4] conan install . --output-folder=build --build=missing
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build .
sudo ./statistics 100 wlp0s20f3
```  

*in last line you should provide two args, first number of packets that after each cycle of those you want report; second is interface name.*  

you need to be root to access the network interface data.
it sends data throw default port 8080, make sure the port is free for use, if not, change the port in code.  

## Prometheus  
After download and extracting the Project from its source :
```
./prometheus --config.file=prometheus.yml
```

* sample prometheus.yml is in /3rdparty dir.  

## Grafana
After installing grafana :

```
sudo systemctl start grafana-server
```

sample dashboard.json is in /3rdparty dir.  
you can access the visualizer at localhost:3000
