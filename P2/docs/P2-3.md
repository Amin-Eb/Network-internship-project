# Capture class  

The class is usable as **PacketCaptureLib**.  

## First release  
Considered two functions for class  

### For capturing pcap packets and parse them as Binary for further usage of Reporter instances  
```
static int fromFile(const std::string& filename, Reporter& analyzer);
``` 

### For capturing pcap packets live from eth interfaces and parse them as binary for further usage of Reporter instances  
```
static int fromInterface(const std::string& ifname,const std::string& bpf_filter, Reporter& analyzer, int limit = 0);
```
it gets limit variable with default value of 0 , limit shows the number of packets we need the function  
to capture from interface, if the value was 0 , it captures till Resurrection!
